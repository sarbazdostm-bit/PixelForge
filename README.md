# 🎨 PixelForge

**مولد هنر پیکسلی برای اندروید با بیش از ۳۰ الگوریتم و ۸ پالت رنگی**

PixelForge یک اپلیکیشن اندروید برای تولید خودکار تصاویر پیکسلی با استفاده از الگوریتم‌های متنوع است. این برنامه کاملاً آفلاین کار می‌کند و به شما امکان می‌دهد تا با انتخاب سبک، پالت رنگی و ابعاد دلخواه، آثار هنری پیکسلی خلق کنید.

## ✨ ویژگی‌های اصلی

### 🎨 الگوریتم‌های تولید (۳۰+ نوع)

| دسته | الگوریتم‌ها |
|------|-------------|
| **موجی** | سینوسی، مثلثی، مربعی، دندانه‌ای، پالس، ترکیبی |
| **هندسی** | دایره، مستطیل، مثلث، شش‌ضلعی، ستاره، بیضی، لوزی، چندضلعی، ترکیبی |
| **فراکتال** | درخت کلاسیک، درخت پیتی، برف‌دانه کخ، مثلث سرپینسکی، ترکیبی |
| **طبیعت** | درخت، جنگل |
| **سایر** | نویز، کاشی، گرادیان، انتزاعی |
| **ویژه** | ترسناک، فراماسونری، نمادها (هندسه مقدس، طلسم‌ها و سیجیل‌ها) |

### 🌈 پالت‌های رنگی (۸ پالت)

| نام | توضیح |
|-----|-------|
| 🌅 غروب (Sunset) | رنگ‌های گرم نارنجی، قرمز و صورتی |
| 🌊 اقیانوس (Ocean) | طیف‌های آبی، فیروزه‌ای و فولادی |
| 🌲 جنگل (Forest) | سبزهای طبیعی و قهوه‌ای |
| 💡 نئون (Neon) | رنگ‌های درخشان و زنده |
| 🌸 پاستل (Pastel) | رنگ‌های ملایم و آرام‌بخش |
| ⚫ تک‌رنگ (Mono) | سیاه، سفید و طیف‌های خاکستری |
| 🕰️ قدیمی (Vintage) | رنگ‌های گرم و کهنه‌نما |
| 🌑 دارک (Dark) | رنگ‌های تیره و عمیق |

### 📐 تنظیمات پیشرفته

- **ابعاد دلخواه**: تنظیم عرض و ارتفاع به صورت جداگانه (از ۱۰ تا ۴۰۰ پیکسل)
- **اندازه پیکسل**: انتخاب سایز پیکسل (۱ تا ۵ پیکسل)
- **تولید با دانه (Seed)**: قابلیت تولید مجدد همان تصویر با یک عدد مشخص

### 💾 ذخیره‌سازی

- ذخیره تصاویر در گالری گوشی
- پشتیبانی از اندروید ۱۰ به بالا (با MediaStore)
- پشتیبانی از اندروید ۹ و پایین‌تر (با دسترسی مستقیم)

### 🤖 قابلیت‌های ویژه

- **تولید پرامپت انگلیسی**: برای استفاده در هوش مصنوعی (مانند DALL-E، Midjourney)
- **کپی پرامپت**: با یک کلیک، پرامپت تولید شده را کپی کنید
- **کاملاً آفلاین**: بدون نیاز به اینترنت کار می‌کند

## 📥 نصب و اجرا

### روش ۱: دانلود APK (ساده‌ترین)

1. به بخش [Releases](https://github.com/sarbazdostm-bit/PixelForge/releases) بروید.
2. آخرین نسخه‌ی APK را دانلود کنید.
3. فایل را نصب کنید (اگر گوشی اجازه نداد، گزینه‌ی "نصب از منابع ناشناس" را فعال کنید).
4. برنامه را باز کنید و لذت ببرید! 🎉
